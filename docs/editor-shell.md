# Editor shell

The Phase 2 editor shell is a desktop-first Next.js interface built with the
official Primer React system and Octicons.

Its fixed product layout contains:

- project identity, save state, undo/redo, command, preview, and publish actions;
- keyboard-operable pages, layers, blocks, assets, code, and settings navigation;
- searchable structural layer tree;
- responsive desktop/mobile canvas controls and selected-block overlay;
- context-sensitive content, layout, spacing, and visibility inspector;
- problems, logs, diff, and activity panel tabs;
- `Ctrl+K` command palette with focus management and Escape dismissal.

The interface uses one dark theme, one orange action/selection accent, 6px panel
radii with 4px compact-control radii, Geist typography, visible focus rings,
and a reduced-motion override.
